Project yang saya buat ini merupakan implementasi fuzzy logic untuk memprediksi tingkat kemacetan jalan berdasarkan data jumlah kendaraan dan kecepatan rata rata dari berbagai jam pengamatan. Dengan menggunakan membership function untuk kategori jumlah kendaraan (sedikit, sedang, banyak) dan kecepatan (lancar, padat, macet), sistem ini mengklasifikasikan status kemacetan menjadi "Lancar", "Padat", atau "Macet". Output dari analisis fuzzy logic divisualisasikan melalui plot distribusi, sehingga dapat memberikan insight mengenai pola kemacetan pada jalan tertentu.
